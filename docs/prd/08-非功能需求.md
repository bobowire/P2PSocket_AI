# 08 · 非功能需求

> 所属文档集：[README](README.md)　编号前缀：NFR

## 1. 性能与可观测（决策 D12：不设硬性数字指标）

| 编号 | 需求 | 优先级 |
|---|---|---|
| NFR-11 | **基准测试报告**为必备交付物：至少覆盖——单隧道吞吐（TCP 映射）、新增延迟（直连/中继分别测量）、并发映射数、服务端并发设备数、打洞成功率（按 NAT 类型分类统计） | P1 |
| NFR-12 | 性能可观测：每映射实时速率/累计流量/当前路径（FR-C-1001）；服务端仪表盘（FR-S-810） | P1 |
| NFR-13 | 资源占用（CPU/内存/句柄）纳入基准报告陈述项，不设阈值 | P1 |
| NFR-14 | 打洞建立耗时目标：P2P 场景下用户可感知层面应"秒级"完成，实测数据进基准报告 | P1 |

## 2. 兼容性

| 编号 | 需求 | 优先级 |
|---|---|---|
| NFR-21 | 客户端：Windows 10 1809+ / Windows 11 / Windows Server 2019+（x64） | P0 |
| NFR-22 | 客户端：主流 Linux 发行版 x64/arm64（Ubuntu/Debian/CentOS 系），内核支持 TUN | P0 |
| NFR-23 | 服务端：Linux 优先（VPS 场景），同构建支持 Windows | P0 |
| NFR-24 | 数据/配置向后兼容：升级版本后既有设备身份、映射配置可延续使用 | P1 |

## 3. 部署与交付

| 编号 | 需求 | 优先级 |
|---|---|---|
| NFR-31 | 单文件自包含发布：客户端/服务端各一个可执行文件，目标机器无需预装运行时 | P0 |
| NFR-32 | Windows 客户端安装包：含虚拟网卡驱动，安装即具备管理员可用的服务与 Web 入口；提供静默安装参数 | P1 |
| NFR-33 | Linux 客户端：二进制 + deb/rpm 包； systemd 单元文件 | P1 |
| NFR-34 | 服务端 Docker 镜像 + docker-compose 示例（含数据卷挂载） | P1 |
| NFR-35 | 全部端口/网段/路径可经配置文件或命令行参数修改；配置错误时给出明确诊断信息 | P0 |
| NFR-36 | 服务端数据（用户/设备/分组/映射）持久化于本地文件或内嵌数据库，随版本升级自动迁移 | P0 |

## 4. 技术栈约束（决策 D13）

| 项 | 约定 |
|---|---|
| 目标框架 | **.NET 10**（LTS，2025-11-11 发布，支持至 2028-11-14） |
| 版本红线 | .NET 8（LTS）与 .NET 9（STS）均于 **2026-11-10 停止支持**，不得作为目标框架；引用库需兼容 .NET 10 |
| 依据 | [Microsoft .NET 支持策略](https://dotnet.microsoft.com/zh-cn/platform/support/policy)、[.NET 生命周期](https://learn.microsoft.com/zh-cn/lifecycle/products/microsoft-net-and-net-core)、[endoflife.date/dotnet](https://endoflife.date/dotnet) |
| Web | ASP.NET Core 内置 Web 服务器，无外部依赖 |
| 发布 | 单文件自包含；NativeAOT 可作为启动优化可选项（技术设计阶段评估） |
