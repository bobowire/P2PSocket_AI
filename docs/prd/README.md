## 已确认的关键决策（摘要）

| # | 决策点 | 结论 |
|---|---|---|
| D1 | 产品形态 | 非中心化内网穿透：服务端只管控制面，客户端之间 P2P 直连传输数据 |
| D2 | 网络模型 | 虚拟网卡 + 独立虚拟 IP（避免与本机地址冲突）；端口手动映射：本机虚拟IP:本地端口 → 目标机器:目标端口 |
| D3 | 中继兜底 | 服务端内置中继；中继回退开关为**目标设备层级配置**——本机对每个目标设备一份配置，该设备下全部映射共用（v0.4/OQ-10 修订，原为逐映射配置） |
| D4 | 产品定位 | 个人 / 小团队自部署，单管理员，几十~几百设备规模 |
| D5 | 隧道协议 | PRD 只定能力（端到端加密、抗 DPI 混淆可扩展、密钥可轮换），不锁定协议实现 |
| D6 | 设备身份 | MAC 生成初始识别码；注册时服务端签发设备 ID 并本地持久化，以服务端 ID 为准 |
| D7 | 远程码 | 服务端下发，仅作设备**地址别名**；能否建映射由"同账号/同分组"授权判定；可重置，重置后旧码失效 |
| D8 | 归属模型 | 分组属于账号、可跨账号共享；未登录设备不能建组，只能加入默认分组或凭邀请码入组 |
| D9 | 分组准入 | 分组级可配置：凭组码即入 / 需分组所有者审批 |
| D10 | 打洞方式 | UDP 打洞 + TCP 打洞（端口预测法：按"打洞并发路数 N"并发连接，目标端口 = STUN 公网端口 +(N−1)；N 可配置 1~5、默认 3 即 +2，OQ-1 决议）；服务端内置 STUN，同时支持 UDP 与 TCP |
| D11 | 管理页访问 | 客户端 Web 仅监听本地回环；服务端 Web 仅本机监听，远程管理通过"服务端机器上部署客户端 + 端口映射"接入；全部使用 HTTP |
| D12 | 性能指标 | 不设硬性数字；要求交付基准测试报告 + 性能可观测（实时速率 / 流量 / 连接状态） |
| D13 | 技术栈 | .NET 10（当前 LTS，支持至 2028-11-14） |
| D14 | 客户端形态 | 系统服务（Windows 服务 / systemd）+ Web 管理页，无 GUI |
| D15 | 映射目标范围 | 默认仅对端客户端本机；对端在本地 Web 显式开放内网 IP 段后，才可映射其对端可达的内网设备 |
| D16 | 初始管理员 | 服务端内置默认账号 **admin / admin**，首次登录提示修改密码（OQ-3） |
| D17 | 升级策略 | 不做自动升级；协议不兼容时自动打开浏览器展示升级提示页，页面内容经服务端稳定接口获取、本地渲染（OQ-5） |
| D18 | 远程码格式 | 6 位字符：数字 0-9 与字母 a/b/c；纯数字组合（10⁶）耗尽前不启用字母（OQ-8） |
| D19 | 映射协议 | TCP（P0）与 UDP（P1）均支持，每条映射单选一种（OQ-6） |
| D20 | 中继回切 | 中继态每 60s 重试直连；切换执行"先排水后切换"保证数据顺序（OQ-7） |
| D21 | 管理面加密 | 现阶段不为控制通道/服务端 Web 引入 TLS，维持全 HTTP（OQ-9） |

## 术语表

| 术语 | 定义 |
|---|---|
| 服务端 | 部署在公网/可达位置的控制面程序：注册、授权、分组、打洞协调、STUN、中继、Web 后台 |
| 客户端 | 部署在各设备上的数据面程序：虚拟网卡、端口映射、隧道转发、本地 Web 管理页 |
| 控制面 | 客户端与服务端之间的管理信道：注册、心跳、信令、配置同步 |
| 数据面 | 客户端之间的业务流量传输路径（P2P 隧道或中继） |
| 虚拟 IP | 服务端下发的虚拟网卡地址，用于本地承载映射监听端口；仅本机用途、允许各设备同值（v0.4/OQ-13） |
| 映射规则 | 一条端口映射配置：本机虚拟IP:本地端口 → 目标机器(远程码):目标端口 |
| 远程码 | 服务端为设备下发的地址别名，用于在配置映射时定位目标设备 |
| 哑节点 | 未登录用户账号的客户端：只可被连接/被发现/配合打洞，不可主动获取业务数据或发起访问 |
| 默认分组 | 服务端预设的全局分组，新设备首启时可直接加入 |
| 邀请码 | 分组所有者生成的入组凭证，配合分组准入策略使用 |
| STUN | 让客户端获知自身公网 IP:端口的探测服务，本产品服务端内置，支持 UDP 与 TCP |
| 打洞 | 双方借助服务端互换公网端点信息后同时向对方发起连接，在 NAT 上建立直达路径 |
| 端口预测 | TCP 打洞技术：依据 STUN 获取的公网端口推算 NAT 将为新一轮连接分配的外部端口 |
| 中继 | 打洞失败时由服务端转发双方密文流量的兜底路径 |
| 直连 | 打洞成功后客户端间点对点传输，流量不经过服务端 |
