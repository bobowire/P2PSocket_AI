# 03 · 功能需求 — 服务端

> 所属文档集：[README](README.md)　编号规则：FR-S-模块号+序号　优先级：P0=M1 / P1=M2 / P2=M3+

## 3.1 注册与身份服务

| 编号 | 需求 | 优先级 | 补充说明 |
|---|---|---|---|
| FR-S-101 | 接收设备注册：客户端提交 MAC 生成的初始识别码及基础信息（OS、主机名、版本） | P0 | 决策 D6 |
| FR-S-102 | 注册成功后签发三要素：**设备 ID**（服务端权威身份）、**远程码**（地址别名）、**虚拟 IP** | P0 | 设备 ID 为持久化凭据，客户端本地保存 |
| FR-S-103 | 设备凭据恢复：设备 ID 丢失（重装系统）时，凭同一 MAC 识别码再注册即**覆盖式恢复**原绑定关系（保留设备 ID/远程码/归属/分组成员资格，重签设备凭据）；原设备在线时拒绝并要求管理员解绑（防伪造 MAC 抢注） | P1 | OQ-14 决议（v0.4，替代原"管理员解绑后再注册"流程）；风险 R2 |
| FR-S-104 | 维护设备心跳与在线/离线状态，超时（默认 30s，可配）标记离线 | P0 | |
| FR-S-105 | 设备禁用：被禁用设备立即断开控制通道、拒绝其后续注册/信令/中继请求 | P1 | 服务端 Web 操作（FR-S-823） |
| FR-S-106 | 记录设备所属账号（登录绑定时）与所加入的分组列表 | P0 | 见 [05](05-账号分组与授权模型.md) |

## 3.2 用户与账号服务

| 编号 | 需求 | 优先级 | 补充说明 |
|---|---|---|---|
| FR-S-201 | 用户注册 API（由客户端 Web 页发起）：用户名 + 密码 | P0 | 开放注册开关默认开启，可在 Web 后台关闭 |
| FR-S-202 | 用户登录/登出；登录态下发至客户端，决定其能力模式（正常/哑节点） | P0 | 能力矩阵见 [05 §3](05-账号分组与授权模型.md) |
| FR-S-203 | 初始管理员：服务端内置默认账号 **admin / admin**，首次登录 Web 后台提示修改密码（不强制阻断） | P0 | 决议 OQ-3；缓解风险 R6 |
| FR-S-204 | 用户禁用：禁用后其名下设备全部转为哑节点（登录态失效） | P1 | |
| FR-S-205 | 密码修改、密码重置（管理员在 Web 后台操作） | P1 | |

## 3.3 分组服务

| 编号 | 需求 | 优先级 | 补充说明 |
|---|---|---|---|
| FR-S-301 | 系统初始化时创建**默认分组**（全局唯一） | P0 | 新设备首启可不登录直接加入 |
| FR-S-302 | 登录用户创建/编辑/解散自己拥有的分组 | P0 | 分组属于账号（决策 D8） |
| FR-S-303 | 生成/撤销分组**邀请码**；凭码入组受该分组准入策略约束 | P1 | |
| FR-S-304 | 分组准入策略：建组时可配置"凭组码即入 / 需所有者审批"（决策 D9） | P1 | 默认分组策略由管理员配置，默认免审批 |
| FR-S-305 | 审批队列：需审批分组中，所有者在客户端 Web/服务端 Web 批准或拒绝入组申请 | P1 | |
| FR-S-306 | 跨账号共享：分组可包含其他账号的设备（凭邀请码加入） | P1 | 组内设备互相可见、可互为映射目标 |
| FR-S-307 | 分组成员管理：所有者可将组内设备移出；设备可自行退出分组（登录态） | P1 | |

## 3.5 打洞协调（信令）服务

| 编号 | 需求 | 优先级 | 补充说明 |
|---|---|---|---|
| FR-S-501 | 接收访问方打洞申请，**校验授权**（同账号或同分组，见 [05 §4](05-账号分组与授权模型.md)）后转发至目标设备 | P0 | 哑节点可接收信令（被动），不可发起申请 |
| FR-S-502 | 为双方互换公网端点信息（IP:端口，来自 STUN 探测结果），并协调双方同时发起连接 | P0 | 时序见 [02 §3.4/3.5](02-总体架构.md) |
| FR-S-503 | 记录打洞结果（成功直连 / 回退中继 / 失败）用于统计 | P1 | 供 Web 后台仪表盘展示 |

## 3.6 STUN 服务（内置）

| 编号 | 需求 | 优先级 | 补充说明 |
|---|---|---|---|
| FR-S-601 | 内置 STUN 服务，支持 **UDP** Binding：返回客户端公网 IP:端口 | P0 | 决策 D10 |
| FR-S-602 | 内置 STUN 服务，支持 **TCP** Binding：返回客户端 TCP 公网 IP:端口 | P1 | TCP 打洞端口预测的数据来源 |
| FR-S-603 | STUN 服务监听端口可配置；仅对本产品客户端认证开放，拒绝未注册来源的滥用 | P1 | 防止被互联网第三方白嫖当公共 STUN 用 |

## 3.7 中继服务

| 编号 | 需求 | 优先级 | 补充说明 |
|---|---|---|---|
| FR-S-701 | 内置中继：打洞失败时为双方建立转发路径，仅转发密文（不可解密） | P1 | 决策 D3；加密能力见 [07 §2](07-安全需求.md) |
| FR-S-702 | 设备层级执行回退策略：访问方对目标设备的回退配置开启时，该设备对隧道打洞失败后其下全部映射启用中继 | P1 | OQ-10 决议（v0.4，原为逐映射）；配置载体见 [06 §2](06-网络与打洞.md) |
| FR-S-703 | 中继全局开关与设备级/全局带宽限速（Web 后台管理） | P2 | 默认不限速 |
| FR-S-704 | 中继承载协议支持 UDP 与 TCP | P1 | 决议 OQ-4：随 M2 一并实现；UDP 被环境封锁场景的兜底 |

## 3.10 远程码管理

| 编号 | 需求 | 优先级 | 补充说明 |
|---|---|---|---|
| FR-S-901 | 远程码生成：设备注册时由服务端生成并下发，全局唯一、便于手工输入 | P0 | 决议 OQ-8：固定 **6 位**，字符集为数字 0-9 与小写字母 a/b/c；**纯数字组合（10⁶）耗尽前不启用字母**，之后扩展至全字符集（13⁶ ≈ 483 万） |
