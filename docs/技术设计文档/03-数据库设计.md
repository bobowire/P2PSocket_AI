# 03 · 数据库设计

> 所属文档集：[README](README.md)　数据库：SQLite（TD-03），EF Core Code First 迁移。表名/字段蛇形命名。

## 1. ER 关系

```
users 1──n devices                （owner_user_id，登录绑定；可为 NULL=未归属）
users 1──n groups                 （owner_user_id，分组属于账号）
devices n──m groups               （group_members）
devices 1──1 remote_code          （devices.remote_code 唯一列）
devices 1──n mappings             （访问方设备拥有的映射，目标以 target_device_id 引用）
devices 1──n lan_segments         （开放内网段白名单）
groups 1──n join_requests         （准入审批队列）
mappings 1──1 mapping_stats       （累计流量统计）
punch_stats                           （打洞结果统计，FR-S-503/810 仪表盘数据源）
```

## 2. 表结构（DDL 摘要）

### 2.1 users — 用户（FR-S-201~205）

```sql
CREATE TABLE users (
  id            TEXT PRIMARY KEY,          -- GUID
  username      TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,             -- PBKDF2-SHA256(100k迭代, 16B盐) Base64
  is_admin      INTEGER NOT NULL DEFAULT 0,
  disabled      INTEGER NOT NULL DEFAULT 0,
  created_at    TEXT NOT NULL,             -- ISO8601 UTC
  updated_at    TEXT NOT NULL
);
-- 初始化：内置 admin（FR-S-203，决议 OQ-3：admin/admin，首登提示改密）
```

### 2.2 devices — 设备（FR-S-101~106）

```sql
CREATE TABLE devices (
  id            TEXT PRIMARY KEY,          -- 服务端签发设备ID（权威身份，D6）
  owner_user_id TEXT NULL REFERENCES users(id),
  device_name   TEXT NOT NULL,             -- 默认 hostname，可改（0x13）
  os            TEXT NOT NULL,             -- windows|linux（FR-S-101）
  client_version TEXT NOT NULL,            -- 客户端版本（FR-S-101，升级引导参考）
  mac_code      TEXT NOT NULL,             -- MAC 派生初始识别码（仅注册时用；同码再注册=覆盖式凭据恢复，OQ-14）
  remote_code   TEXT NOT NULL UNIQUE,      -- 6位：0-9 + a/b/c，纯数字优先（D18/OQ-8）
  virtual_ip    TEXT NOT NULL,             -- 统一下发网段内固定地址（默认 .2，见 §4）；仅本机监听用途、允许重复（OQ-13）
  static_pub_key BLOB NOT NULL,            -- P-256 静态公钥（65B 未压缩）
  device_secret BLOB NOT NULL,             -- 32B HMAC 密钥（下发客户端，DPAPI/0600 存储）
  last_seen_at  TEXT NULL,                 -- 心跳时间（在线判定在内存，超时落库）
  disabled      INTEGER NOT NULL DEFAULT 0,
  created_at    TEXT NOT NULL
);
CREATE INDEX idx_devices_owner ON devices(owner_user_id);
CREATE INDEX idx_devices_mac   ON devices(mac_code);
```

> `device_secret` 需可恢复（服务端校验 Proof/STUN 认证都要用），不哈希存储；库文件本身依赖 OS 文件权限保护（07 §4）。

> **凭据恢复（OQ-14）**：同 `mac_code` 再次注册且原设备**当前离线** → 覆盖式恢复——保留 deviceId / 远程码 / 归属 / 分组成员资格，重签 deviceSecret 并更新 `static_pub_key`（注册请求携带新公钥），存量映射不失效；原设备**在线** → 拒绝（Error 4004 DEVICE_ACTIVE，需管理员解绑，防伪造 MAC 抢注在线身份）。审计事件 `register_recover`。

### 2.3 groups / group_members / join_requests — 分组（FR-S-301~307）

```sql
CREATE TABLE groups (
  id            TEXT PRIMARY KEY,
  name          TEXT NOT NULL,
  owner_user_id TEXT NOT NULL REFERENCES users(id),
  is_default    INTEGER NOT NULL DEFAULT 0, -- 全局唯一默认分组（服务端初始化创建，owner=内置 admin；初始化顺序：先建 admin 用户，再建默认分组）
  join_policy   TEXT NOT NULL DEFAULT 'free',  -- free | approval（D9）
  invite_code   TEXT NULL UNIQUE,          -- 6 位去混淆字符集、全局唯一；撤销=置 NULL（生成规则见 §3）
  created_at    TEXT NOT NULL
);

CREATE TABLE group_members (
  id         TEXT PRIMARY KEY,
  group_id   TEXT NOT NULL REFERENCES groups(id),
  device_id  TEXT NOT NULL REFERENCES devices(id),
  approved   INTEGER NOT NULL DEFAULT 0,
  joined_at  TEXT NOT NULL,
  UNIQUE(group_id, device_id)
);
CREATE INDEX idx_gm_device ON group_members(device_id);

CREATE TABLE join_requests (
  id         TEXT PRIMARY KEY,
  group_id   TEXT NOT NULL REFERENCES groups(id),
  device_id  TEXT NOT NULL REFERENCES devices(id),
  status     TEXT NOT NULL DEFAULT 'pending',  -- pending|approved|rejected
  created_at TEXT NOT NULL,
  handled_at TEXT NULL
);
```

### 2.4 mappings — 端口映射（FR-S-801，字段=PRD 06 §2）

```sql
CREATE TABLE mappings (
  id                TEXT PRIMARY KEY,
  owner_device_id   TEXT NOT NULL REFERENCES devices(id),  -- 访问方设备
  name              TEXT NOT NULL,
  local_port        INTEGER NOT NULL,
  proto             TEXT NOT NULL DEFAULT 'tcp',           -- tcp|udp（D19）
  target_device_id  TEXT NOT NULL REFERENCES devices(id),
  target_addr       TEXT NOT NULL DEFAULT 'self',          -- 'self'=对端本机；否则为开放网段内 IP
  target_port       INTEGER NOT NULL,
  enabled           INTEGER NOT NULL DEFAULT 0,
  created_at        TEXT NOT NULL,
  UNIQUE(owner_device_id, local_port, proto)               -- 同设备同协议本地端口唯一
);
CREATE INDEX idx_mappings_target ON mappings(target_device_id);
```

> 中继回退开关自 v1.5（OQ-10/D3 v0.4）起**不在本表**：为访问方对目标设备的设备级配置，存客户端本地 `peers.json`（§5），不同步服务端。

### 2.5 lan_segments — 开放内网段（FR-C-701，D15）

```sql
CREATE TABLE lan_segments (
  id         TEXT PRIMARY KEY,
  device_id  TEXT NOT NULL REFERENCES devices(id),
  cidr       TEXT NOT NULL,               -- 如 192.168.1.0/24
  enabled    INTEGER NOT NULL DEFAULT 1,
  created_at TEXT NOT NULL,
  UNIQUE(device_id, cidr)
);
```

### 2.6 mapping_stats — 流量统计（FR-C-1001/1002、FR-S-810）

```sql
CREATE TABLE mapping_stats (
  mapping_id   TEXT PRIMARY KEY REFERENCES mappings(id) ON DELETE CASCADE,
  bytes_up     INTEGER NOT NULL DEFAULT 0,   -- 访问方→对端
  bytes_down   INTEGER NOT NULL DEFAULT 0,
  relay_bytes  INTEGER NOT NULL DEFAULT 0,   -- 其中经中继的字节
  updated_at   TEXT NOT NULL
);
```

实时速率不落库（内存滑动窗口 + WS 推送，见 04 §4）；本表仅持久化累计值（周期 30s 刷盘 + 优雅停机刷盘）。

### 2.7 audit_logs — 审计（NFR-54、SEC-51）

```sql
CREATE TABLE audit_logs (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  ts         TEXT NOT NULL,
  event      TEXT NOT NULL,             -- register|login|punch_deny|mapping_deny|disable|...
  device_id  TEXT NULL,
  user_id    TEXT NULL,
  detail     TEXT                       -- JSON 摘要
);
CREATE INDEX idx_audit_ts ON audit_logs(ts);
```

保留策略：默认保留 90 天，启动即清一次、此后每日一轮（可配；与 punch_stats 同一清理任务执行，M2-08）。

### 2.8 server_config — 系统配置（FR-S-825）

```sql
CREATE TABLE server_config (key TEXT PRIMARY KEY, value TEXT NOT NULL);
-- 初始键：registration_open=1, relay_enabled=1, relay_rate_limit=0,
--         stun_auth=1, virtual_subnet=100.64.0.0/24, audit_retention_days=90,
--         log_level=Information（FR-S-825）, max_devices=500（注册设备上限，防滥用，07 §5）,
--         punch_retention_days=90（打洞统计保留，OQ-17）,
--         stun_rate_per_ip=50, stun_rate_per_device=10, stun_circuit_pps=2000（STUN 风暴防护，05 §7.1/TD-18）
-- 端口覆盖键：port_override.control/stun/relay/web（可选，设置后重启生效并优先于配置文件，FR-S-825）
```

> 端口等**进程级**配置在配置文件（08 §5），不进库；库内仅存业务开关。

### 2.9 punch_stats — 打洞结果统计（FR-S-503、FR-S-810）

```sql
CREATE TABLE punch_stats (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  ts           TEXT NOT NULL,
  session_id   TEXT NOT NULL,
  initiator_id TEXT NOT NULL REFERENCES devices(id),
  target_id    TEXT NOT NULL REFERENCES devices(id),
  proto        TEXT NOT NULL,               -- udp|tcp
  concurrency  INTEGER NOT NULL,            -- TCP 打洞 N（0x72 时点取自会话台账，M2-08）
  result       TEXT NOT NULL,               -- direct|relay|failed
  reason       TEXT NULL,                   -- 失败原因码
  duration_ms  INTEGER NOT NULL
);
CREATE INDEX idx_punch_ts ON punch_stats(ts);
```

> 数据来源：0x72 PunchResult（FR-C-404）落库；仪表盘"打洞成功率（近24h）"按 `result` 聚合本表。可选优化（M3）：每日汇总表，首版直查。
> 保留策略：90 天（server_config `punch_retention_days`），随启动清理任务与 audit_logs 一并执行（启动即清一次、此后每日一轮，OQ-17，与审计口径一致，M2-08）。

## 3. 远程码与邀请码生成规则

### 远程码（D18 / FR-S-901）

- 字符集：`0-9`、`a`、`b`、`c`；长度 6；
- 分配策略：先耗尽纯数字空间（`000000`~`999999`，排除全同位/前导规律序列可选），之后扩展至全字符集 13⁶ ≈ 483 万；
- 实现：随机生成 + 唯一索引冲突重试（并发安全由 UNIQUE 约束兜底）；
- 重置（FR-S-903）：生成新码、UPDATE、旧码即刻失效；引用旧码的 mappings 标记 `invalid` 并在双方 Web 提示。

### 邀请码（FR-S-303，OQ-17）

- 随机 **6 位**，字符集去混淆：数字 `2-9` + 小写字母去除 `o/i/l`（31 字符，31⁶ ≈ 8.9 亿组合，便于手工输入）；
- **全局唯一、不重复**：随机生成 + `UNIQUE` 约束冲突重试（同远程码机制）；
- 每分组同时至多一个有效码，撤销 = 置 NULL；
- 首版不设有效期（撤销即失效），有效期列为后续可选项。

## 4. 虚拟 IP 下发（OQ-2 / OQ-13，v1.5 修订）

- 子网可配（默认 `100.64.0.0/24`，CGNAT 段降低与真实内网撞车概率；`.1` 保留）；
- **统一下发固定地址**：子网内主机位 `.2`（随网段配置确定，各设备同值）——虚拟 IP 仅作本机监听地址、不参与节点间寻址（TD-06），**无全局唯一必要**（用户决议 OQ-13）；
- 推论：无地址池、无 253 台上限、无回收问题；设备规模改由 `server_config.max_devices`（默认 500）显式控制（07 §5 防滥用）；
- 本机网段冲突检测（FR-C-204）不变：冲突时管理员调整服务端网段，客户端重连后重新收 IP。

## 5. 客户端本地文件（无数据库）

```
Windows: %ProgramData%\P2PClient\          Linux: /etc/p2p-client/（0600/0700）
├─ state.json        # deviceId、deviceSecret(DPAPI加密/或0600明文+权限)、remoteCode、virtualIp
├─ settings.json     # serverAddrs（域名/主备多候选）、localWebPort=7100、punchConcurrency=3、keepalive 等
├─ peers.json        # 目标设备级配置：{ targetDeviceId → relayFallback }（D3 v0.4 设备层级，OQ-10；不同步服务端）
└─ logs/             # Serilog 滚动文件（保留14天）
```

- `state.json` 写入采用临时文件+原子替换，避免断电损坏；
- 设备凭据保护见 07 §4（SEC-23）。

## 6. 迁移与运维

| 项 | 设计 |
|---|---|
| 迁移 | EF Core Migrations；服务端启动 `db.Database.Migrate()` 自动升级（NFR-36） |
| 备份 | 数据库为单文件 `p2p.db`；文档建议 cron 备份（部署手册说明，NFR-61） |
| 并发 | SQLite WAL 模式（`PRAGMA journal_mode=WAL`）， busy_timeout=5s；写并发低（百级设备）无压力 |
| 回滚 | 迁移向前兼容；重大变更前备份文件即可回退 |
