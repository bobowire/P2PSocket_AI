# 10 · 追溯矩阵（PRD ⇄ 技术设计）

> 所属文档集：[README](README.md)　本矩阵是 PRD 覆盖情况的**唯一权威台账**：正文任何改动必须同步回填本矩阵（tech-design-writer 纪律 1）。
> 图例：✅ = v1.0 起已覆盖　🔧 = v1.3 审查补齐　➕ = v1.4~v1.6 审查补齐与决议修订　⚠️ = 备注事项

## 0. 维护规则

1. 新增/修改任何设计元素（消息、表、接口、模块、页面），先定位其 PRD 编号并回填本矩阵对应行；
2. 正向检查：本矩阵编号全集必须等于 PRD 编号全集（D/OQ/FR-S/FR-C/NET/SEC/NFR/A/F），CI 可解析两侧编号做 diff；
3. 反向检查：设计中无 PRD/TD 依据的元素不得合入（防镀金）；
4. 状态列只升不降：一旦标记覆盖，后续改动不得使其失去落点。
