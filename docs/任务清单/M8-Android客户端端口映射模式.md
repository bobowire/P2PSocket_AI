# M8 · Android 客户端（端口映射模式）· 任务清单

> 所属文档集：[README](README.md)　创建：2026-11-21　状态：◉ **全项收官**（M8-01~08 于 2026-11-21 完成：五套件回归全绿[Core 224→227/Nic 9+6skip/Client 269×3/Server 307/Integration 131]、Android 工程 Release 0 警 0 错、`package.sh android` 签名 APK 入 SHA256SUMS、前端 vitest 90+ui-shared+vue-tsc 零错、375px 走查通过；**M8-07 真机验收 A-19~A-22 于 2026-11-21 四场景全过**——R1[Kestrel on Android] 运行时实证关闭；验收中发现并修复两真机缺陷[清单双 LAUNCHER/Android ECDH ImportParameters]，记录归档 `docs/验收记录/2026-11-21-M8-07-Android真机验收/`）
> **目标**：客户端新增**第四种宿主形态 Android App**（纯 .NET Android 壳：前台服务承载既有 ClientRuntime + WebView 装载既有本地 Web 管理页），以**无卡端口映射模式**（映射监听绑 `127.0.0.1`、NoopNicManager、零 VPN 权限/零 root）把注册/打洞/映射/中继兜底/管理页全套能力带到手机——任意 App 连 `127.0.0.1:本地端口` 直达对端内网；随行完成**前端移动适配**（小屏断点/表格卡片化/侧边栏抽屉化，PC 窄窗口同受益）。控制协议/服务端/加密体系/统计口径零变更（PRD NET-79 · 技术设计 13 号 v0.1 · TD-31~35 · FR-C-814~816）。
> **出口标准**：技术设计 [13 §10](../技术设计文档/13-Android客户端设计.md) 测试口径全绿——①单测（NoopNicManager/LoopbackMappingMode 生效点/指纹注入/EffectiveBindIp）；②集成（无卡模式整跑：Windows 上 LoopbackMappingMode+NoopNicManager 全链注册→映射落 127.0.0.1→隧道 splice 通；展示归真；SpaRootOverride 托管；Web 宿主降级）；③前端（useBreakpoint/卡片双渲染/vitest+vue-tsc 零错+375px 窄屏走查）——＋五套件回归全绿＋`dotnet build src/P2P.Client.Android -c Release` 0 警 0 错＋`package.sh android` 产出签名 APK 入 SHA256SUMS＋**真机验收 A-19~A-22 通过**（需用户配合 adb 装机）。
> **立项背景**：用户需求 2026-11-21（"在手机上运行客户端的功能，在手机上进行内网穿透"）。全仓可行性探查结论：P2P.Core 零 OS 代码（唯一依赖 MessagePack）直接被 net10.0-android 引用；数据面无"包从虚拟网卡进来"假设（`_virtualIP` 仅 4 处引用，监听改绑 loopback 引擎照常）；ClientRuntime 手工组合根+BaseDir/NicOverride 既有缝；集成测试已有 `VirtualIp="127.0.0.1"`+StubNicManager 整跑先例（M1-35）；前端简易版顶部 tab 布局+viewport meta+同源空 baseURL，WebView 装载零障碍。障碍四处（CreateNic 平台分支崩点/MacCode 全设备同值顶号/DefaultBaseDir 非 Win 硬编码/staticwebassets 清单 Android 不产出）均有既有缝或低成本补缝方案（设计 13 §1.3）。
> **决议**（2026-11-21，OQ-23，①②③用户对话定向）：① **Android 先行、iOS 不做**（iOS 沙箱 localhost 不互通+NetworkExtension 付费账号门槛另立项评估）；② **端口映射模式**——映射监听退绑 127.0.0.1，不做透明接入/VpnService（后续增量档位）；③ **界面=WebView 复用现有 SPA＋M8 内移动适配**（否决原生 UI/移动专属页——双份维护数周级）；④ TD-31 纯 .NET Android 不用 MAUI、不进主 sln（脚本守卫式独立构建免全环境装 workload）；⑤ TD-32 无卡模式=LoopbackMappingMode 显式开关+NoopNicManager（state.VirtualIp 不篡改、生效绑定地址含 API 展示统一 127.0.0.1）、TD-34 设备指纹注入 ANDROID_ID（Android 系统 MAC 统一 02:00…全设备同值，覆盖式恢复互相顶号=正确性缺陷）、TD-35 SpaRootOverride+Web 宿主降级不拖垮数据面。
> 任务执行受 [开发规范](../开发规范/README.md) 约束；状态图例与使用规则见清单 README。
